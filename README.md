# GDCHS Website

Static, mobile-friendly website template for Government Dental College, Silchar.

## Files
- index.html — main website
- style.css — design and responsive layout
- script.js — mobile menu + year
- assets/gdchs-logo.jpeg — supplied college logo

## Free hosting with GitHub Pages
1. Create a GitHub account at https://github.com/
2. Create a new PUBLIC repository, e.g. `gdchs-website`.
3. Upload all files from this folder, keeping the `assets` folder.
4. Open repository Settings → Pages.
5. Under "Build and deployment", choose "Deploy from a branch".
6. Select `main` and `/ (root)`, then Save.
7. GitHub will provide a free `github.io` website address.

## Important
This is an informational website template, not an official government website unless the college authorizes and publishes it. Replace placeholder contact details, notices, faculty information, photos and other content with verified official information before public launch.
